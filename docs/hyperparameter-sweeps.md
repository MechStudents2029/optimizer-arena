# Hyperparameter sweeps

Generated by `npm run sweep` (scripts/sweep.ts). Each table varies one hyperparameter of one optimizer at a fixed η, with everything else at its default (β = 0.9, ρ = 0.9, β₁ = 0.9, β₂ = 0.999, ε = 1e-8, AdamW λ = 0.01, Lion β₁ = 0.9, β₂ = 0.99), from the surface's default start, with a 10,000-step budget and a constant rate unless the heading says otherwise. Every run is deterministic.

The Lion sweeps use a cosine schedule and a start nudged off Lion's η-lattice: from Beale's own start, (1, 1.5), Lion at η = 0.01 lands exactly on the minimum (3, 0.5), and the sweep would measure that coincidence instead of β (see [lr-schedules.md](lr-schedules.md)).
